<h1 align="center">🍹 MJITO — Animated Café Landing Page</h1>

<p align="center">
  An Awwwards-inspired, fully interactive animated landing page for a café brand — showcasing advanced GSAP animation techniques, scroll-triggered effects, and premium UI design built with React and Tailwind CSS.
</p>

<p align="center">
  <a href="https://mojito-landing-page-azure.vercel.app/">🌐 Live Demo</a> · <a href="https://alimoradpour.vercel.app">Portfolio</a>
</p>

---

## ✨ Features

- 🎬 **GSAP timeline animations** — precisely choreographed entrance, scroll, and exit effects
- 📜 **Scroll-triggered interactions** — elements animate as the user navigates the page
- 🖱️ **Cursor & hover effects** — custom cursor tracking and interactive hover states
- 🍃 **Smooth page transitions** — fluid section-to-section navigation
- 🎨 **Awwwards-level design** — bold typography, layered visuals, and deliberate spacing
- 📱 **Responsive layout** — fully functional across mobile, tablet, and desktop
- ⚡ **Optimised performance** — lightweight animation setup with minimal layout thrash

---

## 🛠️ Tech Stack

| Layer       | Technology              |
|-------------|--------------------------|
| Framework   | React 18                 |
| Animations  | GSAP (GreenSock)         |
| Scroll      | GSAP ScrollTrigger       |
| Styling     | Tailwind CSS             |
| Build Tool  | Vite                     |
| Deployment  | Vercel                   |

---

## 🎯 What This Demonstrates

This project was built as a **showcase of advanced front-end animation skills**:

- **Timeline sequencing** — staggered reveals with fine-grained `gsap.timeline()` control
- **ScrollTrigger integration** — pinning, scrubbing, and trigger-point configuration
- **Performance awareness** — using `will-change`, `transform`, and GPU-composited properties to avoid jank
- **Design sensibility** — translating a high-end visual brief into working, animated code
