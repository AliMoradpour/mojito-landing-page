<h1 align="center">🛍️ NextShop — E-Commerce Storefront</h1>

<p align="center">
  A clean, responsive e-commerce storefront built with Next.js and Tailwind CSS, demonstrating modern file-system routing, component-based architecture, and a smooth shopping UI.

## ✨ Features

- 🗂️ **Next.js App Router** — structured page routing with layouts
- 🎨 **Tailwind CSS** — rapid, responsive UI development
- 🛒 **Shopping interface** — product listings, detail views, and cart UX patterns
- 📱 **Fully responsive** — optimised for mobile, tablet, and desktop
- ⚡ **Next.js font optimisation** — auto-loads Inter via `next/font`
- 🚀 **Vercel-ready** — deploy with a single click

## 🚀 Getting Started

### Prerequisites

- Node.js ≥ 18

### Installation

```bash
git clone https://github.com/AliMoradpour/NextShop.git
cd NextShop
npm install
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

### Build

```bash
npm run build
npm start
```
